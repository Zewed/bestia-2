# Le combat additionne les forces, sans seuil de taille

Les caractéristiques des Espèces sont calquées sur les animaux réels, mais le combat reste une simple somme : assez de souris finissent par tuer un mammouth. On a envisagé une règle d'écart de taille (un petit ne peut pas blesser un géant) avec le venin et l'essaim comme exceptions ; on l'a écartée pour garder un combat simple et lisible. Le réalisme passe par les chiffres de chaque Espèce, pas par des règles de combat.
